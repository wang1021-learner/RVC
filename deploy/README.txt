============================================
  RVC 实时语音转换 - 使用说明
============================================

【一、安装虚拟声卡】
  1. 下载 VB-Cable: https://vb-audio.com/Cable/
  2. 解压后右键点击 VBCABLE_Setup.exe → 以管理员身份运行
  3. 安装完成后重启电脑
  4. 确认：右下角音量图标 → 声音设置 → 应出现 "CABLE Input" 和 "CABLE Output"

【二、启动程序】
  双击 RVC实时语音转换.exe 即可运行，无需安装 Python

【三、添加角色模型】
  1. 点击左侧「添加」按钮
  2. 输入角色名称（如"小美"）
  3. 点击「浏览」选择模型文件（.pth）
  4. 可选：选择索引文件（.index），不选则检索比例设为0
  5. 设置音高：男声转女声 +12，女声转男声 -12，同性别 0
  6. 点击确定

【四、设置音频设备】
  输入设备：选择你的物理麦克风
  输出设备：选择 CABLE Input (VB-Audio Virtual Cable)

【五、开始转换】
  1. 点击底部绿色「启动转换」按钮
  2. 状态栏显示"实时转换已启动"后即可说话
  3. 对方在通话软件中需将麦克风设为 "CABLE Output"

【六、切换角色】
  在左侧角色列表中点击不同角色即可切换
  可实时调整音高和检索比例

【七、常见问题】

  Q: 电音/杂音严重？
  A: 确认检索比例设为0，尝试调高"音量保留"到0.5

  Q: 延迟太高？
  A: 减小"块大小"到0.15秒，减小"额外推理"到1.5秒

  Q: 声音断续？
  A: 增大"块大小"到0.3秒，关闭"输入降噪"和"输出降噪"

  Q: 对方听不到声音？
  A: 确认输出设备选择了 CABLE Input，通话软件麦克风选择了 CABLE Output
