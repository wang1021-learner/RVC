RVC 实时变声 · 服务器客户端
================================

本包只有界面和声卡，不含模型和显卡推理。
变声计算在另一台「推理服务器」上。

【你的电脑】
- Windows 10/11 64 位
- 麦克风 + 耳机/扬声器
- 能访问推理服务器所在网络（同一局域网即可）
- 不需要 NVIDIA 显卡

【推理服务器（管理员准备）】
- 已放置模型：assets/weights/*.pth
- 已放置索引：logs/ 下的 .index
- 已启动服务：
  - CPU 机器：start_server_cpu.bat
  - 有 NVIDIA：start_server.bat
- 防火墙放行 TCP 8765

【使用步骤】
1. 双击「RVC实时变声-服务器版安装.exe」，按向导安装
   （也可解压绿色包，直接运行文件夹里的 exe）
2. 安装完成后从开始菜单或桌面打开「RVC实时变声」
3. 右侧「预设与监听」勾选远程服务器
4. 地址填写：ws://服务器IP:8765
   例如 ws://192.168.1.10:8765
5. 点「连接」，成功后再选角色、点「启动变声」
6. 卸载：开始菜单里的「卸载 RVC实时变声」，或 Windows 设置 → 应用

【注意】
- 本包无法「安装本地推理」，也不要指望离线变声
- 延迟会比本机 GPU 略高（多一跳网络）
- CPU 服务器会更卡，只适合验证；流畅实时请用带显卡的推理机
- 角色列表和服务器地址存在 %AppData%\RVC实时变声\，覆盖安装不会冲掉
